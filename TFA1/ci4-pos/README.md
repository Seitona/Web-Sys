# CodeIgniter POS Foundations

Simple four-page CodeIgniter 4 POS activity.

## Run

1. Start Apache in the XAMPP Control Panel.
2. Open `http://localhost/Web-Sys/TFA1/ci4-pos/public/` in a browser.
3. Or run `php spark serve` and open the URL it shows.

Pages: `/`, `/about`, `/customers`, and `/users`.
